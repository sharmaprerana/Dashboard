# Prerana Sharma CV Dashboard

A static CV dashboard built from Prerana Sharma's CV. This repository is ready for GitHub Pages deployment.

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch, usually `main`, and the root folder `/`.
5. Save. GitHub will publish the dashboard at the Pages URL shown there.

## Files

- `index.html` - the dashboard entry page for GitHub Pages.
- `.nojekyll` - tells GitHub Pages to serve the static files exactly as written.
